# SizeCompare 新主线：行李箱 × 航空随身行李限制检查器

## Context

竞品调研结论（HypeStat 硬数据）：通用科普对比赛道除病毒现象级头部（thetruesize 176 万/月）外全部 <10 万/月；而商品尺寸赛道有已验证可复制模式（carsized 单类目 188 万/月、上游 gsmarena 5,265 万/月）。经用户确认转向：**做"我的行李箱能带上这架飞机吗"检查器**——搜索意图强（购买/出行决策）、数据集小而精确（航司公开限制 + 厂商规格）、affiliate 变现直接、完全空白无竞品。

现有站点资产全部保留：真比例渲染引擎、单位换算、溯源台账制度、191 对象 + 111 对比页（降为长尾区）。

数据策略（本环境航司官网被 Cloudflare 拦截，已实测）：**规范值种子**——行李限制是多年稳定的公开事实（美系大厂 22×14×9in 行业标准、Ryanair 55×40×20/40×20×25 等），每条带官方来源 URL + checked_at + 台账 ⏳ 标记；WebSearch 配额 11-26 恢复后批量核验 top-20；页面明示"以航司官方为准"。

## 架构

### 1. 数据库（两个新数据文件，尺寸统一 mm 基准）

**`src/data/airlines.ts`（~40 家航司）**
```ts
interface Airline {
  slug, name, iata, country, region: 'US'|'EU'|'APAC'|'ME'|'CA';
  carryon: { h, w, d, weight_kg?, notes }        // mm，含轮政策注明
  personalItem?: { h, w, d, notes }
  strictness: 'standard'|'strict'|'ultra'         // Ryanair/Wizz/Spirit = ultra
  source_url, source_name, checked_at             // 官方页面链接
}
```
覆盖：US 9 家（Delta/United/AA/Alaska/JetBlue/Southwest/Hawaiian/Spirit/Frontier）+ EU 12 家（Ryanair/EasyJet/Wizz/BA/Lufthansa/Air France/KLM/Iberia/Vueling/Norwegian/TAP/Turkish）+ APAC 8 家（ANA/JAL/Singapore/Cathay/Qantas/Air China/China Eastern/Korean Air）+ 中东 3 家（Emirates/Qatar/Etihad）+ 加 2 家。搜索优先级：ULCC 严限航司页面价值最高（"ryanair cabin bag" 是刚需词）。

**`src/data/luggage.ts`（~40 款热门行李箱）**
```ts
interface Luggage {
  slug, brand, model, name;
  dims: { h, w, d }; weight_kg; volume_l?;       // 外廓含轮，厂商规格
  sizeClass: 'personal-item'|'carry-on'|'intl-carry-on'|'check-in';
  source_url, source_name, checked_at;
  priceQuery?: string;                            // 预留 Amazon 检索词（affiliate 后接）
}
```
覆盖：Away（Carry-On/Bigger/The Farrier）、Samsonite、Travelpro、Monos、Beis、Calpak、July、Level8、Delsey、Briggs & Riley、Amazon Basics 等 + 常见通用尺寸段（18"/20"/21"/22" 国际版）。

### 2. 判定引擎 `src/lib/luggage.ts`（纯函数 + vitest）

- `checkFit(bag, airline, mode)` → `{ verdict: 'fits'|'tight'|'no-fit', overage: {h,w,d}, weightWarn? }`
  - 三维逐项比对（front H×W + 深 D）；任一维超 = no-fit；余量 ≤20mm = tight
  - 重量：航司有限重且行李箱自重+估装（自重+5kg 常规负载）接近限重 → weightWarn
  - `mode: 'carryon' | 'personal'`（个人物品模式，Ryanair 免费袋场景）
- `fitsOnMatrix(bag, airlines)` → 全航司判定表（行李箱页用）
- `compliantBags(airline, luggage)` → 该航司合规箱列表（航司页用）
- 测试：精确压线 1mm、tight 阈值、personal 模式、限重警告、矩阵完整性、两个 DB 的 slug 唯一性与字段完备性

### 3. 检查器 island `src/components/carryon/CarryOnChecker.tsx`

- 航司选择（按区域分组 + 搜索）→ 行李箱选择或**自定义尺寸输入**（cm/in 切换，复用 units.ts）
- **可视化**：SVG 真比例渲染——航司限制箱画为虚线框（sizer box），行李箱画实心（正面 H×W 视图 + 侧面 D 视图并排），超出部分红色溢出——这是核心卖点，完全复用现有 SVG 内联规范（导出 PNG 兼容）
- 判定卡：FITS ✅ / TIGHT ⚠️ / NO FIT ❌ + 逐维余量 + 重量提示 + "limits change — check [官方链接]" 免责
- GA4 聚合事件：checker_start / airline_selected / fit_checked(verdict)

### 4. SEO 页面矩阵（~200 新页）

- 航司页：限制表（cm+in）、重量、个人物品、严苛度徽章、**自动生成的合规行李箱推荐列表**、检查器入口、官方来源链接、FAQPage JSON-LD
