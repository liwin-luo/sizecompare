# SizeCompare 重做 — 通用 Compare 平台（尺寸/重量/体积）

## Context

用户决定把产品从「教师优先的尺寸对比工具」转向**通用 compare 平台**：用户在这里找到想比较的东西，比较多维度属性。已确认决策：通用受众（删除教师页面）、首发尺寸+重量+体积三属性、对象库 ~50 个、生成 25–40 个精选对比对静态页。

现有代码本会话从零建成，复用面大：单位换算引擎（mm 基准）、真比例渲染 ScaleCanvas、20 个带来源对象、自绘剪影库、PNG 导出/打印 CSS、Astro 脚手架全部保留；重做数据模型（多属性）与发现层（搜索/浏览/对比页）。

## 架构调整

### 属性系统（新 `src/lib/attributes.ts`）
- `AttributeKey = 'height'|'length'|'width'|'diameter'|'weight'|'volume'`
- 对象模型 v2：`measurements: Partial<Record<AttributeKey, Measurement>>`，每个属性独立携带 value/min/max/context/source_url/source_name/checked_at/uncertainty_note（沿用 v1 溯源字段设计）
- 现有 20 对象迁移到 v2（原 dimension 字段拆入 measurements）

### 单位引擎扩展（`src/lib/units.ts`）
- 重量：基准 g；g/kg/t/lb/oz（1 lb = 453.59237 g 精确）；英制 lb+oz 组合显示
- 体积：基准 ml(=cm³)；ml/l/m³/fl oz/cup/US gal（1 gal = 3785.411784 ml 精确）
- 长度补 km 单位；MAX 上限提高到 10,000,000 km（容纳太阳直径 1.39M km）

### 可视化引擎（三种，共享标签/诚实性注记组件）
| 属性族 | 组件 | 方式 |
|---|---|---|
| 高度/长度/宽度/直径 | 现有 `ScaleCanvas` | 真比例并排 + 尺寸线（沿用） |
| 重量 | 新 `WeightBars` | 横向条形图，条长严格按真实比例；比值标注 |
| 体积 | 新 `VolumeSpheres` | 球体半径 ∝ ∛V（三维诚实缩放），画布注明缩放规则 |

极端比值沿用「警告而非偷偷放大」原则；答案句扩展（"is about 66× heavier than" / "has about 3× the volume of"）。

### 对象库 ~50 个（`src/data/library.ts` v2 + 台账更新）
类别重组：Animals(~18，含新增 T. rex/北极熊/鸵鸟等)、Everyday(~15，原 classroom 并入)、Food(~6)、Space(地球/月球/太阳/木星/火星，NASA fact sheet)、Buildings(埃菲尔/哈利法塔/自由女神/珠峰)、Vehicles(自行车/轿车/校车/皮卡)。每个对象 1–3 个有源属性（动物身高+体重最全；体积只给可辩护对象：易拉罐 355ml、天体、篮球等）；数据核源 + `docs/objects-data.md` v2 台账（置信度标注 + 复审计划）。

### Compare Studio（重构 `ComparisonTool` → CompareStudio）
- 选择器升级：**搜索框**（50 对象模糊匹配）+ 分类页签 + 自定义输入（属性下拉含重量/体积）
- **属性页签**：由选中对象自动推导可用属性；无共同属性时明确提示
- 属性族切换对应三种可视化；编辑面板文案通用化（"Classroom question"→"Question"，投屏/导出/打印保留）
- URL：`/tools/size-comparison-maker/` → `/studio/`（站点未公开，无需 301）

### 发现层 + 对比对静态页
- 首页 v2：搜索优先 hero（"What do you want to compare?"）+ 热门对比 + 分类入口 + 属性说明区
- `/compare/` 索引页：分类浏览 + 热门对
- **对比对页** `src/pages/compare/[...slug].astro` + `src/data/pairs.ts`（~30 精选对 + 每对手写一句 blurb）：`/compare/blue-whale-vs-elephant/` 等；嵌入预加载该对象对的 Studio island（SSR 出内容供 SEO），含数据表/来源/答案句/进 Studio CTA。**只做精选不做 N² 组合**（质量门槛沿用原规划 §6.6）
- 动物页保留并扩展重量列；about/privacy 文案通用化

### 删除项
`/size-comparison-for-kids/`、`/guides/how-to-teach-big-and-small/`、导航中 For Teachers/Guide、教师框架文案；`docs/product-plan-v1.1.md` 由 v2.0 取代（保留归档）。
