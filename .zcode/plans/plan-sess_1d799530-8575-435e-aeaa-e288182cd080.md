## Context

输入是一份产品规划书（`/Users/luogangming/Downloads/sizecompare-visual-comparison-product-plan.md`），建议把 SizeCompare.org 从「家具空间适配工具」转向「教师优先的可视化尺寸对比制作工具」。用户要求：分析需求合理性 → 调整 → 规划执行。项目目录 `/Users/luogangming/projects-b/sizecompare/` 为空，全新建设。

## 一、合理性分析结论：方向合理，研究可信，需 6 处调整

**已验证的可信点**（抽查 4 个关键竞品链接全部真实、描述准确）：
- LessonCraftStudio（worksheet 订阅制 $69/年，已扩展到 26 种题型）— worksheet 赛道确实拥挤
- Dragoon Apps（555 对象、3D、自定义、PNG 导出）— 通用比较器无空白
- **HandyToolkits 已覆盖裁剪版 MVP 约 70% 的功能面**（自定义输入、同比例、尺寸标注线、8 对象、PNG、分享链接、"不上传数据"）
- Peabody（407 组动物对比，含儿童参照）

**核心判断**：文档的差异化结论成立，但窗口更窄——真正的空隙**只在教师工作流**：投屏模式、练习纸导出、课堂提问/答案显隐、测量口径与数据来源标注（§4.3）。这 4 项是差异化本体，必须进 P0；通用比较功能反而不能作为卖点。

**6 处调整**：
1. **投屏 + 练习纸导出锁死 P0**（差异化本体）；分享链接、图片上传、独立 PDF 生成库移出 MVP（打印 CSS + 浏览器另存 PDF 已满足 A4/Letter）
2. **Phase 0 改为「原型优先」**：不做前置教师访谈（无渠道），公开上线后用数据 + 社区反馈验证
3. **首期 SEO 页面 11 个 → 7 个**（遵守文档自己的发布准入标准）
4. **内置对象 20–40 个 → 16 个**：每个对象都要来源核验 + 原创 SVG + 授权记录，内容成本高于想象
5. **上线暂不接 AdSense**：先 CWV + 28 天数据基线，再申请（文档 §8.5 自己的判断）；变现叙事记入规划
6. **修正文档内部矛盾**：§4.2 Step1 的 Image 入口与 §5.2 P1 矛盾 → MVP 明确不做图片上传

## 三、执行计划（7 个阶段）

### Phase 1：规划落库 + 项目脚手架
- `docs/product-plan-v1.1.md`：调整版产品规划（分析结论、6 处调整、裁剪版 MVP 定义、路线图）——这是"调整"的正式交付物
- git init；Astro + React + TypeScript 脚手架；vitest；`@astrojs/sitemap`
- `src/layouts/BaseLayout.astro`（TDK/canonical/OG）、Header/Footer、设计基调（教师工具、干净、高对比、非幼儿风）
- 提交 1：scaffold + 规划文档

### Phase 2：核心引擎（逻辑先行 + 测试）
- `src/lib/units.ts`：单位换算，内部统一 mm（cm/m/mm/in/ft + 英制 ft-in 显示）
- `src/lib/scale.ts`：共同尺度因子、极端比例处理
- `src/lib/objects.ts`：对象数据模型（含 §4.3 全部元数据字段：measurement_context、source_url、checked_at、uncertainty_note 等）+ 校验
- vitest 覆盖 §9.4 清单：换算精度、零/负/极端值、尺度因子、维度不匹配警告逻辑
- 提交 2：引擎 + 测试全绿

### Phase 3：工具 UI（React island，`/tools/size-comparison-maker/`）
- `src/components/tool/` 下：ComparisonTool（状态）、ObjectPicker（内置库）、CustomObjectForm、ScaleCanvas（SVG：并排 + 参照物模式、尺寸线、基线、标签，纵横比锁定禁止拉伸）、编辑面板（标题/提问/答案显隐/单位切换）
- PresentationMode：Fullscreen API + 大字版式 + 提问揭晓
- ExportPanel：PNG（SVG→canvas）+ 打印 CSS（`src/styles/print.css`，A4/Letter）
- localStorage 自动保存 + 3–5 个示例项目
- 提交 3：工具可用

### Phase 4：内置对象库内容生产（16 个）
- 课堂：铅笔、橡皮、30cm 尺、书、课桌、门（高度）
- 日常：苹果（直径）、篮球（24.6cm，NBA 官方）、网球、A4 纸（ISO 216）、信用卡（ISO/IEC 7810 ID-1）、易拉罐
- 动物：老鼠、猫、狗、大象、长颈鹿、蓝鲸（长度）
- 参照：儿童身高（1.2m，标注为例示值）、成人（1.7m，例示值）→ 共 16+ 条
- 每条：来源 URL 逐条核验（ISO/NBA/博物馆/大学）、原创几何风 SVG 剪影（自绘，规避版权）、uncertainty_note
- `src/data/library.ts` + `docs/objects-data.md` 来源台账
- 提交 4：对象库

### Phase 5：首批 SEO 页面（7 个）
- `/`（首页，嵌入可交互示例）、`/tools/size-comparison-maker/`、`/size-comparison-for-kids/`（**教师框架措辞**，面向教小孩的老师，非儿童向）、`/animal-size-comparison/`（示例画廊）、`/guides/how-to-teach-big-and-small/`、`/privacy`、`/about`
- JSON-LD（WebApplication/FAQPage 仅真实 FAQ）、sitemap、robots、GA4 聚合事件（tool_start / comparison_generated / export_png / print_started / presentation_started，无 PII）
- 提交 5：页面齐

### Phase 6：质量验证 + 上线
- 浏览器实测（browser-use）：大象 vs 老鼠 → 自定义铅笔 vs 橡皮 → 投屏 → 导出 PNG → 打印预览，5 任务全通过
- Lighthouse：SEO / 性能 / 可访问性 ≥ 90；移动端适配检查
- `npm run build` 干净通过
- 部署 Cloudflare Pages（需用户提供账号或 wrangler 授权；否则交付构建产物 + 部署指引）；GSC 提交 sitemap（用户操作）

### Phase 7（上线后，非本次开发）：28 天数据基线 → 决定 worksheet maker / 分享链接 / AdSense 接入
