# Size Quiz（答题模式）+ area 属性家族 + 国家数据 —— 一次做全

## Context

用户要给 sizecompare.org 加答题玩法：对比国家/物品尺寸，答题后用动画揭晓。探索确认：

- **题库零成本**：195 对象 + 111 对精选 `PAIRS`（自带提问句），`buildAnswerSentence`（ScaleCanvas.tsx:104）直接生成揭晓答案句。
- **但全站没有动画**：三个画布（ScaleCanvas/WeightBars/VolumeSpheres）都是纯静态 SVG 渲染器，需自建揭晓动画。
- **地理是全新家族**：无 `area` 属性、无面积单位换算、无国家数据、无面积可视化。

核心机制：**出题时两个对象等大小显示（隐藏真实比例）→ 答题后画布动画过渡到真实比例揭晓**。等大布局和真实布局插值（progress 0→1），动画本身就是答题机制。

用户已定：一次做全（物品+国家）；地理收全球国家 Top 60 + 6 个小国对照（暂不做省市区/城市）；10 题一局+结算+分享。

⚠️ 开始前：当前工作区有一批未提交改动（上一波商业对象/行李箱计划遗留），先让用户确认提交或暂存，避免与本批混在一起。

## Part 2 — 国家数据 + 旗帜资产（~66 条带溯源）

- **来源**：CIA World Factbook total area（land + water），全库单一口径，`context: "total area (land and water)"`、`checked_at: '2026-11-21'`。集合 = 面积 Top 60 国家 + Vatican/Monaco/Liechtenstein/Luxembourg/Belgium/Netherlands 6 个小国对照。
- **条目形态**（ObjectV2）：`category: 'place'`、`primaryAttr: 'area'`、`measurements: { area: {...} }`（value 为 mm²）、`aspect: 1, axis: 'both'`、`image: '/objects/flag-china.svg'`、`image_license: 'fluent-emoji-MIT'`。国家无线性属性，不会被线性画布渲染。`silhouette` 需非空——在 `silhouettes.tsx` 加一个极简 `place-square` 占位剪影。
- **资产管线**（沿用 scripts/emoji-tools 三波惯例）：先验证 `@iconify-json/fluent-emoji` 含旗帜图标（如 `flag-china`）；若缺则回退无 image（方块+名称仍完整可用）。新写 `wave-places.py`：内联表（id/name/area_km2/旗帜名）生成 library 条目片段 + fluent-map.json 追加，再跑 `build-fluent-assets.py` 产出 `public/objects/*.svg`。
- **`src/data/library.ts`**：追加 66 条 + `CATEGORY_LABELS` 加 `place: 'Places'`（studio 选择器分类自动出现，需确认选择器遍历逻辑）。
- **`src/data/pairs.ts`**：新增 ~15 对手工精选 area 对（china-vs-united-states、brazil-vs-australia、russia-vs-monaco 一两对戏剧级 + 常规 1.2–50× 比值对），blurbs 手写（延续"禁止模板生成"惯例），每对生成一个新 SEO 对比页。

## Part 3 — Quiz 引擎 + 揭晓动画

- **`src/lib/quiz.ts`（新建，纯函数）**：
  - `QuizQuestion { aId, bId, attr, ratio, tier }`；
  - `buildQuestionPool()`：精选 PAIRS（111 对）+ 自动生成（同 attr 共享、比值 ∈ [1.2, 80]、双方该属性可渲染；含国家 area 组合，≈2000+ 候选）；确定序排序保证池稳定；
  - `tierFromRatio`：easy ≥3× / medium 1.6–3× / hard 1.2–1.6×；
  - `pickRound(pool, seed)`：mulberry32 种子随机，3易+4中+3难、同局对象不重复、难度递进排列；
  - `biggerSide(q)` 判分。
- **`src/components/quiz/useReveal.ts`（新建）**：`useReveal(active, 900ms)` rAF 驱动 progress，easeOutCubic，`prefers-reduced-motion` 直接跳 1。
- **`src/components/quiz/QuizGame.tsx`（新建 island）**：状态机 intro → asking（画布 reveal=0 等大显示 + 两张大按钮 A/B）→ 选后 revealing（动画插值 + 正误横幅 + `buildAnswerSentence` 揭晓句）→ next → 10 题后 summary（得分、最佳纪录 localStorage `sizecompare:quiz:v1`、错题列表跳 `/compare/{pairSlug}/`、navigator.share/剪贴板分享文案、Play again 换种子）。键盘 1/2 选择、Enter 下一题，`aria-live` 播报判分。画布按 family 切换四组件，全部传 reveal。
